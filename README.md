# Vertical — Themes for T3Code

> Curated themes for [T3Code](https://github.com/pingdotgg/t3code), meticulously inspired by the iconic liquid glass gradient aesthetics of **Arc Browser**. Designed with rich vertical sidebars, elevated card surfaces, and fine-tuned dark and light palettes. Fully compliant with [t3themes.com](https://t3themes.com).

---

## 🎨 Themes Included

### 1. `Vertical` (Flagship)
- **Dark Mode (Arc Emerald Glass):** Deep smoky sage/emerald-tinted glass background (`#0f1715`) with luminous mint accents (`#2dd4bf`), elevated card containers, and serene contrast.
- **Light Mode (Arc Coral Sunset):** Vibrant coral-peach liquid glass sidebar (`#ff7575`) with elevated white rounded tab capsules (`#ffffff`), translucent glass toolbar controls, and warm blush canvas.

### 2. `Vertical Frost`
- **Light Mode (Arc Icy Cyan Glass):** Crisp, fresh azure/cyan gradient glass (`#42bfd8`) with white elevated content cards and electric blue accents (`#0284c7`).
- **Dark Mode (Arctic Midnight):** Deep oceanic midnight slate (`#0b121e`) with neon electric cyan highlights (`#38bdf8`).

## 🚀 How to Install in T3Code

### Option A: Import via T3Code Settings (Easiest)
1. Open **T3Code**.
2. Go to **Settings** (`Cmd + ,`) → **Appearance** → **Colors & themes**.
3. Under the Themes section, click **Add theme** → **Theme JSON**.
4. Select or paste the contents of [`themes/vertical.json`](themes/vertical.json).
5. Enjoy your new theme!

### Option B: Quick Copy & Paste
You can also open the raw JSON file from this repository:
- Raw link: [`themes/vertical.json`](themes/vertical.json)
- Copy the entire JSON and import it into T3Code.

### Option C: Theme Editor Panel
- Press **`Cmd + Option + Shift + T`** inside T3Code to open the live **Theme Editor**.
- Customize or fine-tune any color token with the built-in color picker and inspector.

> **Pro Tip:** Switch between your installed themes at any time with the global shortcut **`Cmd + Option + A`**.
